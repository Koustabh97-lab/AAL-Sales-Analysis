# AAL Clothing Sales Analysis

## Project Overview
AAL, established in 2000, is a well-known brand in Australia, particularly recognized for its clothing business[cite: 1]. This project analyzes the sales data of the company for the fourth quarter in Australia on a state-by-state basis to assist the company in making data-driven decisions[cite: 1].

## Folder Structure
* **`data/`**: Contains the dataset (`AusApparalSales4thQrt2020.csv`)[cite: 1].
* **`notebooks/`**: Contains the Jupyter Notebook (`project 1.ipynb`) with data wrangling, analysis, and visualization[cite: 1, 2].
* **`docs/`**: Contains the original problem statement (`1739523775_sales_analysis_problem_statement.docx`).

## Key Objectives
* Identify states generating the highest and lowest revenues[cite: 1].
* Analyze time-of-the-day sales patterns (Morning, Afternoon, Evening)[cite: 1, 2].
